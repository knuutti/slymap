    How to Use

    Works out a map's calib for data/games.json from a few spots whose in-game position you know, then lets you click objects onto a calibrated map for its .hson data.

    Calibrating

    1. Choose a map, or open an image file. A map's own objects load with it; for a new map, load its .hson file(s) to see them on the image once there is a fit.
    2. Click a spot on the image whose in-game position you know, then type that position as X, Y. Drag a point to fine-tune it.
    3. Once objects are shown, click one and choose Use as reference point, then click where it really is.
    4. With two or more points, Result shows the fit and how far off each point is. Copy the snippet into the map's entry in data/games.json.

    Collecting objects

    1. Switch to Collect Objects and give the object a type. Choosing a type the map already has copies one of its objects' shape and parameters.
    2. Click the image to add it. Positions come from the current fit (the points' fit, or the map's own calib) and follow it if it changes.
    3. Copy the entries, or download them as a new .hson or added to the map's own file.

    Mouse and keyboard

    Click the imageAdd a point, or an object while collecting.
    Drag a pointMove it.
    EnterFinish typing a position, or a path or area.
    BackspaceRemove the last corner of a path or area.
    EscapeStop placing; close a menu or this dialog.
    Drop files on the imageOpen an image and load .hson files.
    Ctrl+O, F1Open an image, this help.

    Points are remembered in this browser for each image.
